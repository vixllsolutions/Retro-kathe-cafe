# Retro Kathe Cafe & Bistro — Website Bundle

A self-contained, responsive one-page cafe website. It uses plain HTML, CSS and JavaScript; no build tools or package installation are needed.

## Files

- `index.html` — page structure, accessible navigation, menu sections, testimonials and contact information.
- `style.css` — retro-inspired visual design, responsive layouts, hover states and motion preferences.
- `script.js` — filterable/searchable menu, mobile nav, reveal-on-scroll and gallery lightbox.
- `assets/` — all bundled supplied food, cafe and poster imagery, plus review screenshots retained as source references. The live website uses review text cards instead of embedding review screenshots.

## Run locally

Open `index.html` in a modern browser. For local web server preview, run `python3 -m http.server 8080` from this folder and visit `http://localhost:8080`.

## Publish on GitHub Pages

Upload `index.html`, `style.css`, `script.js`, `README.md` and the `assets` folder to the root of your repository. In GitHub, open **Settings → Pages** and select the desired branch and `/ (root)` as the source.
